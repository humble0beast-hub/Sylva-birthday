# Project Sylva — Birthday Experience

A responsive, password-gated birthday website for My Stubborn Potato. Built with Node.js and Express so the password check and access cookie are handled on the server. All four photos and five videos are served only after successful authentication.

## Local preview (Windows)

1. Install Node.js 18 or newer.
2. Open PowerShell in this folder.
3. Run `npm.cmd install`.
4. Create `.env` in this folder with:

   ```env
   SITE_PASSWORD=Sylva
   SESSION_SECRET=replace-this-with-a-long-random-secret
   ```

5. Run `npm.cmd start`.
6. Open `http://localhost:3000`.

Keep the PowerShell window open while testing. Stop the server with Ctrl+C.

## Deploy to Render

This project needs a Node web service; do not upload it as a static site. The included `render.yaml` configures a Render web service, production mode, health check, and a generated session secret. The password is deliberately configured as a private environment variable.

1. Create a GitHub account if you do not already have one.
2. Create a new private repository named `project-sylva`.
3. Upload the contents of this folder to the repository (not the outer ZIP folder). Include `render.yaml`; do not upload `.env` or `node_modules`.
4. In Render, choose **New → Blueprint**, connect that GitHub repository, and apply the blueprint.
5. When Render asks for `SITE_PASSWORD`, enter `Sylva`. Keep `SESSION_SECRET` generated by Render.
6. Wait for the deployment to finish. Render will provide a public `onrender.com` URL.
7. Open the URL in a private/incognito browser and test the password, photos, videos, and navigation.

The free Render service may sleep when idle and take a little time to wake on the first visit.

## Notes

- The login cookie is an HTTP-only browser-session cookie. A fresh browser session should ask for the password again; browsers that restore previous sessions may restore session cookies too.
- The password is checked on the server. Do not put `.env` in GitHub or share the `SESSION_SECRET`.
- The ambient sound is an optional synthesized tone and starts only after the visitor taps the music control.
- Videos attempt muted autoplay when the gallery opens. Browser and device power settings may prevent simultaneous playback; tapping a video opens it larger with controls.
